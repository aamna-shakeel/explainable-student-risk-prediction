# Reliability-Aware Explainable AI for Student Academic Risk Prediction

## Overview
This project aims to develop a machine learning-based system for identifying students at risk of poor academic outcomes and explaining the factors contributing to its predictions.

The project will focus on both predictive performance and the reliability of explanations generated by Explainable AI (XAI) techniques.

## Objectives
- Compare Logistic Regression, Random Forest, and XGBoost for student academic risk prediction.
- Evaluate models using precision, recall, F1-score, and PR-AUC, where appropriate.
- Use SHAP to explain individual predictions and identify influential features.
- Assess explanation consistency across different data splits and model runs.
- Develop an interactive dashboard to display predictions, explanations, and evaluation results.

## Technologies
- Python
- Pandas and NumPy
- Scikit-learn and XGBoost
- SHAP
- Matplotlib and Seaborn
- Streamlit
- Jupyter Notebook

## Dataset
The project will use a suitable publicly available educational dataset. Data preprocessing, class imbalance, and prevention of data leakage will be considered during experimentation.

## Expected Outcome
A functional educational risk prediction application supported by comparative experiments and an evaluation of explanation reliability.

## Project Status
Proposal and initial planning.

## Responsible Use
The system is intended for educational research and decision support, not as a definitive judgment of a student's abilities. Predictions may be uncertain and should not replace human judgment.
